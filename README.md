# 🚀 PyCraft Launcher

**PyCraft Launcher** — это современный, лёгкий и стильный кастомный лаунчер для Minecraft, написанный на Python с использованием PyQt6. Разработан с акцентом на удобный UI/UX, высокую скорость ( да да на питоне )) )  работы и гибкое управление сборками.

---

### ✨ Ключевые особенности

* 🎨 **Современный UI:** Минималистичный тёмный интерфейс с фиолетово-розовыми акцентами и кастомизацией.
* 👤 **Профили и изоляция:** Создавайте отдельные профили со своими модами, мирами, ресурс-паками и настройками управления.
* 📦 **Интеграция с Modrinth:** Поиск, скачивание и установка модов, шейдеров и ресурс-паков прямо из лаунчера.
* 🔍 **Управление зависимостями:** Автоматическая проверка и предложение установки недостающих библиотечных модов (Fabric API и др.).
* 🔌 **Поддержка авторизации:** Вход через лицензию, Ely.by и оффлайн-режим.
* 🎛️ **Удобный менеджмент модов:** Быстрое включение/выключение модов с помощью тумблеров без необходимости вручную переименовывать файлы.
* 🎮 **Discord Rich Presence:** Отображение текущего статуса игры и выбранной версии в вашем Discord.
* ⚙️ **Гибкая настройка:** Выделение ОЗУ, кастомные аргументы Java, авто-скрытие окна при запуске и встроенный менеджер логов.

---

### 🛠️ Технологии

* **Язык:** Python 3.11+
* **Интерфейс:** PyQt6
* **API:** Modrinth API, Ely.by Auth API
* **Зависимости:** `pypresence`, `requests`

---

### 💻 Сборка и запуск из исходников

```bash
# Клонировать репозиторий
git clone [https://github.com/arsenycapybara-svg/PyCraft-Launcher.git](https://github.com/arsenycapybara-svg/PyCraft-Launcher.git)

# Перейти в директорию
cd PyCraft-Launcher

# Установить зависимости
pip install -r requirements.txt

# Запустить лаунчер
python main.py
